Starts per task

A “start” = each time you began or returned to a task. Consecutive work on the same task counts once; work intervals under 1 min are ignored.

Switches by hour

A “switch” = moving from one task to a different one (resuming the same task isn’t a switch). Counted by the clock hour you switched into.

Session timeline

Each bar is one continuous work session at its real clock time, colored per task. Pausing & resuming the same task with nothing in between stays a single session; intervals under 1 min are dropped. Bars may overlap when multiple tasks ran at once.

Context switches per day

Daily count of moves between different tasks (resuming the same task isn’t a switch; work intervals under 1 min ignored). Grey hatched bars mark days that had activity but no recorded interval data (before interval tracking existed).

Estimation calibration
